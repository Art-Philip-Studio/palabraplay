¿CÓMO SE JUEGA?

HILARIO — Sopa de letras temática

👆 Arrastra el dedo (o ratón) por las letras adyacentes para formar palabras
🔵 Palabras del tema se marcan en azul — encuéntralas todas para ganar
⭐ El PANGRAMA (dorado) cruza el tablero de lado a lado — ¡la más larga!
💡 Encuentra 3 palabras extra (no del tema) para ganar una pista
🔗 Las letras se conectan en cualquier dirección — horizontal, vertical o diagonal
